CLI open source para a 42 Network

A 42 inteira, direto do terminal.

Perfil, avaliações, slots, mapa do campus, subjects, notificações no celular, um simulador de provas offline e testes automáticos dos seus projetos. Um binário só, sem dependências.

$curl -fsSL https://tinyurl.com/lightyear42 | sh

Linux (como nas máquinas da 42) e macOS. Sem sudo: instala em ~/.local/bin, confere o sha256 e põe no PATH. Outras formas · Guia de instalação

        01
        
App em tela cheia canary

        
Rode só lightyear e ele abre um app no terminal, com abas clicáveis e mouse: tudo o que os comandos mostram, num lugar só.

        
    
          
  • Início, Avaliações, Projetos, Campus, Slots e Exam.
    • 
          
  • Na aba Exam, e abre o subject e a sua entrega lado a lado no editor do lightyear.
    • 
          
  • Com as notificações configuradas, avisa de avaliação nova enquanto está aberto.
    • 
        

        
lightyear

        05
        
Notificações no celular

        
Um push no celular sempre que surge uma avaliação nova na sua agenda, via ntfy: sem conta e sem app próprio.

        
    
          
  • setup gera o tópico e mostra como assinar.
    • 
          
  • Deixe rodando com watch, ou ponha check no cron.
    • 
        

        
lightyear notify setuplightyear notify testlightyear notify watch

        Configurar as notificações →
      

      

        
lightyear notify --help


Envia uma notificação push quando aparece uma avaliação nova na sua
agenda — como avaliador ou como avaliado.

A entrega usa o ntfy (https://ntfy.sh): instale o app no celular, assine o
tópico gerado pelo "lightyear notify setup" e pronto.

Fluxo típico:

  lightyear notify setup    # gera o tópico e mostra como assinar
  lightyear notify test     # confirma que chega no celular
  lightyear notify watch    # deixa rodando; avisa a cada avaliação nova

        07
        
Simulador de provas

        
O examshell no seu computador: sorteia o exercício, cronometra, corrige e sobe de nível. Funciona offline, só precisa de um compilador C (e de Python para os Ranks 03 a 05).

        
    
          
  • Os 56 exercícios em C do Exam Rank 02 e os 28 em Python dos Ranks 03, 04 e 05, com enunciado em inglês e português.
    • 
          
  • Correção de verdade: cc -Wall -Wextra -Werror, os mesmos testes no seu código e numa solução de referência.
    • 
          
  • Trace claro de cada falha: compilação, saída diferente, crash ou timeout.
    • 
        

        
lightyear exam startlightyear exam grademelightyear exam practice ft_split

        Como o simulador funciona →
      

      

        
lightyear exam grademe

        08
        
Testes de projeto canary

        
Na raiz do projeto, lightyear test abre o editor com a árvore de arquivos e um botão ▶ Rodar testes. Centenas de casos por projeto, tirados do subject.

        
    
          
  • libft, ft_printf, get_next_line, os módulos de Python 00 a 10 (e 05/06 bis) e born2beroot.
    • 
          
  • Cada caso roda isolado: segfault, loop infinito, vazamento, double free e malloc sem proteção aparecem caso a caso.
    • 
          
  • Clique num erro e vá direto à linha. Ou rode sem editor com --run.
    • 
        

        
lightyear test libftlightyear test ft_printf --runsudo lightyear test born2beroot

        09
        
Editor embutido canary

        
Um editor modal estilo Vim dentro do lightyear, com syntax highlighting do Tree-sitter e language server para C, C++, Go, Python e Rust.

        
    
          
  • Erros do compilador na linha, K, gd, autocomplete, renomear e formatar.
    • 
          
  • Buffers, janelas, text objects, macros e . para repetir.
    • 
          
  • Temas com :colorscheme. Clique num aqui ao lado.
    • 
        

        
:colorscheme draculagdK:Format

        10
        
Atualização e canais

        
O lightyear se atualiza sozinho pelo GitHub Releases, sem gerenciador de pacotes. Escolha entre a versão estável e a canary, que recebe as novidades antes.

        
    
          
  • --check só verifica; --yes não pergunta.
    • 
          
  • --canary entra no canal canary; --stable volta.
    • 
        

        
lightyear updatelightyear update --canarylightyear update --stable

        Atualizar e trocar de canal →
      

      

        
lightyear update --canary

        11
        
Configuração em dois minutos

        
Um guia cria a aplicação OAuth na Intra, faz o login e instala o autocomplete do seu shell. O token fica no keyring do sistema.

        
    
          
  • Keychain no macOS, Secret Service no Linux, Credential Manager no Windows.
    • 
          
  • Tudo o que fica no disco tem um caminho só: lightyear config path.
    • 
        

        
lightyear setuplightyear loginlightyear config show

        Primeiros passos →
      

      

        
lightyear --help
