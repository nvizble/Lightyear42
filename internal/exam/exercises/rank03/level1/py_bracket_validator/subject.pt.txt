Os delimitadores são (), [] e {}. A string é válida quando todo delimitador
aberto é fechado por um do mesmo tipo, na ordem certa, e nenhum fechamento
aparece sem a sua abertura. Qualquer outro caractere é ignorado. A string
vazia é válida.

Exemplos:

bracket_validator("()")            -> True
bracket_validator("()[]{}")        -> True
bracket_validator("(]")            -> False
bracket_validator("([)]")          -> False
bracket_validator("{[]}")          -> True
bracket_validator("hello(world)")  -> True
bracket_validator("((())")         -> False
bracket_validator("")              -> True
