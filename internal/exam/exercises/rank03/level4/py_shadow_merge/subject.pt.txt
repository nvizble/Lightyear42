Nome do exercício : py_shadow_merge
Arquivos esperados: py_shadow_merge.py
Funções permitidas: todas as builtins
--------------------------------------------------------------------------------

Escreva uma função que junta duas listas ordenadas em uma só lista
ordenada.

def shadow_merge(list1: list[int], list2: list[int]) -> list[int]:

As duas listas já vêm em ordem crescente e podem estar vazias, ter
números negativos ou repetir valores. Retorne uma nova lista com todos os
elementos das duas listas, em ordem crescente. Os valores repetidos são
todos mantidos.

Exemplos:

shadow_merge([1, 3, 5], [2, 4, 6])   -> [1, 2, 3, 4, 5, 6]
shadow_merge([1, 2, 3], [4, 5, 6])   -> [1, 2, 3, 4, 5, 6]
shadow_merge([1], [2, 3, 4])         -> [1, 2, 3, 4]
shadow_merge([], [1, 2, 3])          -> [1, 2, 3]
shadow_merge([1, 1, 2], [1, 3, 3])   -> [1, 1, 1, 2, 3, 3]
shadow_merge([-5, -1], [-3])         -> [-5, -3, -1]
shadow_merge([], [])                 -> []
