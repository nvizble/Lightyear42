Nome do exercício : py_mirror_matrix
Arquivos esperados: py_mirror_matrix.py
Funções permitidas: todas as builtins
--------------------------------------------------------------------------------

Escreva uma função que espelha uma matriz na horizontal.

def mirror_matrix(matrix: list[list[int]]) -> list[list[int]]:

A matriz é uma lista de linhas, e cada linha é uma lista de inteiros.
Devolva uma nova matriz com as mesmas linhas na mesma ordem, cada uma
invertida.

As linhas podem ter tamanhos diferentes, e uma linha vazia continua vazia.
Uma matriz vazia dá uma matriz vazia. Não modifique a matriz recebida nem
as suas linhas (o mesmo objeto de linha pode aparecer mais de uma vez).

Exemplos:

mirror_matrix([[1, 2, 3], [4, 5, 6]])    -> [[3, 2, 1], [6, 5, 4]]
mirror_matrix([[1, 2], [3, 4], [5, 6]])  -> [[2, 1], [4, 3], [6, 5]]
mirror_matrix([[7]])                     -> [[7]]
mirror_matrix([[1, 2, 3, 4]])            -> [[4, 3, 2, 1]]
mirror_matrix([[-1, -2], [-3, -4]])      -> [[-2, -1], [-4, -3]]
mirror_matrix([[1, 2], [3, 4, 5], []])   -> [[2, 1], [5, 4, 3], []]
mirror_matrix([])                        -> []
