Assignment name  : py_sliding_window_maximum
Expected files   : py_sliding_window_maximum.py
Allowed functions: all builtins
--------------------------------------------------------------------------------

Write a function that returns the maximum of every window of k consecutive
elements of a list.

def sliding_window_maximum(nums: list[int], k: int) -> list[int]:

Slide a window of size k over nums from left to right, one position at a
time, and return the list of the maximums of each window, in order. For a
list of n elements there are n - k + 1 windows.

If k is 0 or negative, or greater than len(nums) (which includes an empty
nums), return an empty list.

Your solution must be fast: the tests use lists of 100000 elements with
windows of 50000, so computing max() of every window separately will be
too slow. Aim for linear time.

Examples:

sliding_window_maximum([1, 3, -1, -3, 5, 3, 6, 7], 3)  -> [3, 3, 5, 5, 6, 7]
sliding_window_maximum([1, 2, 3, 4, 5], 2)             -> [2, 3, 4, 5]
sliding_window_maximum([5, 4, 3, 2, 1], 1)             -> [5, 4, 3, 2, 1]
sliding_window_maximum([4, 4, 4, 4], 2)                -> [4, 4, 4]
sliding_window_maximum([1, 2, 3], 3)                   -> [3]
sliding_window_maximum([1, 2, 3], 4)                   -> []
sliding_window_maximum([1, 2, 3], 0)                   -> []
sliding_window_maximum([], 2)                          -> []
