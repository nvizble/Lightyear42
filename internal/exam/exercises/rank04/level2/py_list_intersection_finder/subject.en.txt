Assignment name  : py_list_intersection_finder
Expected files   : py_list_intersection_finder.py
Allowed functions: all builtins
--------------------------------------------------------------------------------

Write a function that finds the values common to several sorted lists.

def list_intersection_finder(lists: list[list[int]]) -> list[int]:

Each inner list is sorted in ascending order and may contain duplicates.
Return a new list with every value that appears in ALL the inner lists,
each value once, in ascending order.

If lists is empty, or any inner list is empty, return an empty list. With
a single inner list, the result is that list without duplicates.

Examples:

list_intersection_finder([[1, 2, 3], [2, 3, 4], [2, 3, 5]])         -> [2, 3]
list_intersection_finder([[1, 2, 3, 4], [2, 4, 6, 8], [4, 8, 12]])  -> [4]
list_intersection_finder([[1, 1, 2, 3], [1, 2, 2, 3], [1, 2, 3]])   -> [1, 2, 3]
list_intersection_finder([[1, 2], [2, 3], [3, 4]])                  -> []
list_intersection_finder([[1, 2, 3], []])                           -> []
list_intersection_finder([[5, 5]])                                  -> [5]
list_intersection_finder([])                                        -> []
