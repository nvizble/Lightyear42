Assignment name  : ft_range
Expected files   : ft_range.c
Allowed functions: malloc
--------------------------------------------------------------------------------

Write the following function:

int     *ft_range(int start, int end);

It allocates (with malloc()) an array of ints, fills it with the consecutive
values going from start to end (both start and end included!), and returns a
pointer to the first element of the array.

Examples:

- For (1, 3) the array holds 1, 2 and 3.
- For (-1, 2) the array holds -1, 0, 1 and 2.
- For (0, 0) the array holds 0.
- For (0, -3) the array holds 0, -1, -2 and -3.

Turn in the function only, without a main.
