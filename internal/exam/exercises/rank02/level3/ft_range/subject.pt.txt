Nome do exercício : ft_range
Arquivos esperados: ft_range.c
Funções permitidas: malloc
--------------------------------------------------------------------------------

Escreva a seguinte função:

int     *ft_range(int start, int end);

Ela aloca (com malloc()) um array de ints, preenche-o com os valores
consecutivos que vão de start até end (start e end incluídos!) e retorna um
ponteiro para o primeiro elemento do array.

Exemplos:

- Para (1, 3) o array contém 1, 2 e 3.
- Para (-1, 2) o array contém -1, 0, 1 e 2.
- Para (0, 0) o array contém 0.
- Para (0, -3) o array contém 0, -1, -2 e -3.

Entregue apenas a função, sem main.
