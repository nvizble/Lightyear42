Assignment name  : rstr_capitalizer
Expected files   : rstr_capitalizer.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that receives one or more strings and, for each argument,
turns the last character of every word into uppercase (when that character is
a letter) and every other letter into lowercase, then prints the result
followed by a \n.

A word is a run of characters delimited by spaces/tabs or by the start/end of
the string. A word made of a single letter must be put in uppercase.

A letter is a character in the set [a-zA-Z].

If there are no arguments, print only \n.

Examples:

$> ./rstr_capitalizer | cat -e
$
$> ./rstr_capitalizer "a FiRSt LiTTlE TESt" | cat -e
A firsT littlE tesT$
$> ./rstr_capitalizer "SecONd teST A LITtle BiT   Moar comPLEX" "   But... This iS not THAT COMPLEX" "     Okay, this is the last 1239809147801 but not    the least    t" | cat -e
seconD tesT A littlE biT   moaR compleX$
   but... thiS iS noT thaT compleX$
     okay, thiS iS thE lasT 1239809147801 buT noT    thE leasT    T$
$>
