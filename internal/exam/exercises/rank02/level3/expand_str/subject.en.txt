Assignment name  : expand_str
Expected files   : expand_str.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that receives a string and prints it with exactly three
spaces between consecutive words, with no spaces or tabs at the start or at
the end, followed by a newline.

A word is a run of characters delimited by spaces/tabs, or by the start/end
of the string.

If the number of arguments is not 1, or if the string contains no words, print
only a newline.

Examples:

$> ./expand_str "See? It's easy to print the same thing" | cat -e
See?   It's   easy   to   print   the   same   thing$
$> ./expand_str " this        time it      will     be    more complex  " | cat -e
this   time   it   will   be   more   complex$
$> ./expand_str "No S*** Sherlock..." "nAw S*** ShErLaWQ..." | cat -e
$
$> ./expand_str "" | cat -e
$
$>
