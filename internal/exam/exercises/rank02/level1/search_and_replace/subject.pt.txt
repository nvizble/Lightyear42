Nome do exercício : search_and_replace
Arquivos esperados: search_and_replace.c
Funções permitidas: write, exit
--------------------------------------------------------------------------------

Escreva um programa chamado search_and_replace que recebe 3 argumentos: uma
string, uma letra a ser procurada (2º argumento) e a letra que a substitui
(3º argumento). Ele exibe a string com cada ocorrência do 2º argumento
trocada pelo 3º, seguida de uma quebra de linha.

Se o número de argumentos for diferente de 3, apenas uma quebra de linha é
exibida.

Se o 2º argumento não aparecer na string, a string é exibida sem alteração,
seguida de uma quebra de linha.

Exemplos:
$>./search_and_replace "Papache est un sabre" "a" "o"
Popoche est un sobre
$>./search_and_replace "zaz" "art" "zul" | cat -e
$
$>./search_and_replace "zaz" "r" "u" | cat -e
zaz$
$>./search_and_replace "jacob" "a" "b" "c" "e" | cat -e
$
$>./search_and_replace "ZoZ eT Dovid oiME le METol." "o" "a" | cat -e
ZaZ eT David aiME le METal.$
$>./search_and_replace "wNcOre Un ExEmPle Pas Facilw a Ecrirw " "w" "e" | cat -e
eNcOre Un ExEmPle Pas Facile a Ecrire $
