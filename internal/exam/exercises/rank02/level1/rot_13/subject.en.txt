Assignment name  : rot_13
Expected files   : rot_13.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes a string and displays it with every letter
replaced by the letter 13 positions further along the alphabet, wrapping
around at the end.

So 'z' turns into 'm' and 'Z' turns into 'M'. Letters keep their case;
characters that are not letters are displayed unchanged.

The output ends with a newline.

If the number of arguments is not 1, the program displays only a newline.

Examples:

$>./rot_13 "abc"
nop
$>./rot_13 "My horse is Amazing." | cat -e
Zl ubefr vf Nznmvat.$
$>./rot_13 "AkjhZ zLKIJz , 23y " | cat -e
NxwuM mYXVWm , 23l $
$>./rot_13 | cat -e
$
$>
$>./rot_13 "" | cat -e
$
$>
