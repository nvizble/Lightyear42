Assignment name  : ft_list_foreach
Expected files   : ft_list_foreach.c, ft_list.h
Allowed functions: none
--------------------------------------------------------------------------------

Write a function that receives a list and a function pointer, and applies that
function to every element of the list, in order.

It must be declared as follows:

void    ft_list_foreach(t_list *begin_list, void (*f)(void *));

The function pointed to by f must be called like this:

(*f)(list_ptr->data);

You must use the structure below, and turn it in in a file named ft_list.h:

typedef struct    s_list
{
    struct s_list *next;
    void          *data;
}                 t_list;

Turn in the function only, without a main.
