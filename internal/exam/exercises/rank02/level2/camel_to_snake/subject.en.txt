Assignment name  : camel_to_snake
Expected files   : camel_to_snake.c
Allowed functions: malloc, realloc, write
--------------------------------------------------------------------------------

Write a program that takes one string written in lowerCamelCase and prints
it converted to snake_case, followed by a newline.

In lowerCamelCase, every word starts with an uppercase letter, except the
first word.

In snake_case, every word is written in lowercase and words are joined by an
underscore "_".

Examples:
$>./camel_to_snake "hereIsACamelCaseWord"
here_is_a_camel_case_word
$>./camel_to_snake "helloWorld" | cat -e
hello_world$
$>./camel_to_snake | cat -e
$
