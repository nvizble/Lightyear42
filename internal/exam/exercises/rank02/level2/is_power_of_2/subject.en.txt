Assignment name  : is_power_of_2
Expected files   : is_power_of_2.c
Allowed functions: none
--------------------------------------------------------------------------------

Write a function that tells whether a given number is a power of 2.

It returns 1 when the number is a power of 2, and 0 in every other case.

It must be prototyped as follows:

int	    is_power_of_2(unsigned int n);

Turn in the function only, without a main.
