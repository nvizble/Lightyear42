Assignment name  : do_op
Expected files   : do_op.c
Allowed functions: atoi, printf, write
--------------------------------------------------------------------------------

Write a program that takes three strings:
- The first and the third are base-10 signed integers that fit in an int.
- The second is one arithmetic operator among: + - * / %

The program prints the result of that operation, followed by a newline.
If the number of arguments is not 3, the program prints only a newline.

You may assume the strings are well formed, with no stray characters.
A negative number, whether in the input or in the output, has exactly one
leading '-'. The result of the operation fits in an int.

Examples:

$> ./do_op "123" "*" 456 | cat -e
56088$
$> ./do_op "9828" "/" 234 | cat -e
42$
$> ./do_op "1" "+" "-43" | cat -e
-42$
$> ./do_op | cat -e
$
